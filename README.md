# Dre Dev Tools

Free calculators for the trades (HVAC, electrical, floor coating) that promote the Dre Dev apps.

- `build.py` generates the static site into `site/`. It is served at https://zhukovskyi.space/calculators/: in the `my_space` repo run `python3 tools/sync_calculators.py`, then `./deploy.sh`.
- `docs/` (GitHub Pages, the old address andronaft.github.io/dredev-tools) holds only redirect pages to the new address. Commit and push it when the list of pages changes.
- PT data, screenshots and icons are read from the app repos next to this folder (`~/Desktop/mobile_sub_app/*`), so the build runs only on that machine. Commit the regenerated `site/` and `docs/` after every build.
- `config.json`: site URL, store links and the beta tester group. Fill a link in, run `python3 build.py`, commit, push.
- `assets/calc.js` mirrors the apps' Dart engines (PT interpolation, voltage drop, coating coverage). Keep them in step.
- Trust pages (`trust.py`): `methodology.html`, `verification.html` (checked examples) and `changelog.html`. Add a line to `CHANGES` in `trust.py` whenever a formula or a number changes.
- `verification.json`: rows from the sources next to the expected answer. `build.py` runs them through `assets/calc.js` (`tools/verify.mjs`, needs `node`) and stops if one is off. Change `"checked"` only after reading the sources again: that date is printed on the calculator pages.
- Pages load scripts and styles as `assets/calc.js?v=<8 hex of the file's SHA-256>` (`version_assets()` at the end of `build.py`): Cloudflare and browsers keep assets for up to 4 hours, so a changed file needs a new address. Write plain `assets/calc.js` in page code; the build adds the version.
- `lastmod.json`: hash and date of each page's content, so the sitemap's `lastmod` and `dateModified` move only when a page really changes. Commit it with `site/`.
- The apps have no pages here any more: links go to `zhukovskyi.space/apps/<slug>/`. `config.json` still decides the buttons: set `google_play_live` or `app_store_url` and the "Become a tester" button becomes a store link.
- Tests: `python3 build.py && python3 -m unittest discover tests && node --test "tests/*.test.mjs"`.
- Share image: `/usr/bin/python3 tools/og_image.py` writes `assets/og.jpg`.
- Reference pages live in their own modules and are plugged into `build.py` with one call each: `pages_hvac.py` (the superheat and subcooling calculator for all refrigerants, opened on one of them with `#r-454b` in the address; six refrigerant pages with their own text in `SPECIFICS`; the body of the PT chart pages, comparisons, target superheat, guides, the HVAC hub) and `pages_electrical.py` (ampacity chart, wire size by distance, voltage drop references, subpanel feeders, conduit fill, box fill, EV charger circuits, the NEC edition by state, the electrical hub; the state table is read from the app's `state_code.dart` on `origin/main`, and `STATES_CHECKED` in `pages_electrical.py` is the day it was last read against NFPA's page; the conduit, box and grounding tables are read from the app's `nec_tables.dart` at build time, and the fill arithmetic is the Electrician Calc section of `calc_math.py`). Shared pieces are in `pagekit.py`; their script and print styles are `assets/ref-pages.js` and `assets/ref-pages.css`.
- `refdata.py` holds every fact that is not a pressure (GWP, safety class source, lubricant, what a refrigerant replaces) with the page it was read on and the check date. No source, no entry: the page then leaves the field out.
- Tests: `python3 -m unittest discover -s tests` (needs Node). They rebuild the site, run the real `assets/calc.js` in Node and compare it and the app repos' source tables with the numbers on the pages, then check the sitemap, the section navigation and every internal link.
- Hobby and trade calculators (brewing, hydroponics, candles, coffee, knitting, roofing, concrete, garage coating, pool chlorine, shift patterns) live in `pages_hobby.py` and `pages_trades.py`, with shared pieces in `calcs_common.py`; `build.py` wires them in with `calcs_more.build()`, which also adds their rows to the methodology, the changelog and the category menu. The maths is in `calc_math.py` (static tables) and `assets/calc-more.js` (live calculators); both mirror the apps' Dart engines. Slab sizes and pool volumes are rows of one table on one page, not pages of their own: a row's link (`#20x20`, `#15000-gallons`) loads that size into the calculator, and `?size=20x20` or `?gallons=15000` does the same from outside. Do not generate a page per size.
- `pages_data.py` writes the open data page `hvac/refrigerant-pt-data.html` and the files `hvac/data/refrigerant-pt.csv` and `.json` from the same PT tables as the charts. Every PT source must have an entry in its `SOURCES` (id, basis, address, retrieval date) or the build stops. Raise `VERSION` when a cell changes. The same files are prepared for a GitHub repo and Zenodo in `my_space/promo/open-data/` (`python3 tools/export_open_data.py` there copies them).
- Calculators built on `calc.js` (voltage drop, lye, superheat) register their embed copy with `calcs_common.embed_copy()`; the hobby and trade ones with `embed=` in `calcs_common.page()`. `build.py` writes the embed page after all of them (`calcs_more.build_embed()`).
- `embed/` holds bare copies of some calculators for iframes on other sites (`pages_embed.py`). They only work once the server stops sending `X-Frame-Options: SAMEORIGIN` for `/calculators/embed/`.
- `embed/uk/` holds the Ukrainian widgets (battery runtime, battery-to-inverter cable, voltage drop) and their page (`pages_embed.build_uk()`). The battery card is the one of `electrical/uk/battery-runtime.html` (`pages_electrical.UK_CARDS`); the other two run on `assets/embed-uk.js` (calc.js's IEC voltage drop constants and the Electrician Calc app's IEC 60364-5-52 Table B.52.2, method C). The line under every iframe is "Calculator: Dre Dev Tools" with `rel="nofollow"`: a keyword anchor that passes link weight is a link scheme under Google's guidance on widgets. On the server, the nginx exemption from X-Frame-Options must cover `/calculators/embed/uk/` too (my_space `ops/nginx-zhukovskyi.space.conf`).
- `tests/test_calc_math.py` pins the control values of the apps' own unit tests for `calc_math.py` and checks `assets/calc-more.js` against it through `node`; `tests/test_site.py` checks the built hobby and trade pages.
