31 rows from the published sources, each next to what the calculator answers for the same input. The answers on this page are produced by the calculators' own code when the site is built.

If an answer falls outside the allowed difference, the build stops and nothing is published. Where the calculator and the source differ on purpose, the row says why. The sources were last read against these rows on 12 November 2026.

You can repeat any row yourself: open the calculator, enter the example and compare. The same list runs as an automated test in the public repository (verification.json).
